# copilot-app-skills
Reusable skills for the GitHub Copilot app.

## Personal skills

[copilot-attribution](.copilot/skills/copilot-attribution/SKILL.md) requires external interactions on your behalf to start with the exact unformatted line `🤖Copilot🤖`, with the message body starting on the next line. It covers PR descriptions, comments, review replies, commit messages, and analogous communications.

The skill source is in `.copilot\skills\copilot-attribution\SKILL.md`. To use it as a personal skill, copy the `copilot-attribution` directory into your user-level `.copilot\skills` directory (on Windows, `%USERPROFILE%\.copilot\skills`). Adding it to this repository does not install or enable it globally.
